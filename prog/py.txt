## 🧭 خريطة تعلم شاملة (من الصفر حتى المستوى الوظيفي)

### 🎯 المرحلة 1: أساسيات البرمجة بلغة Python
**المدة المقترحة:** 2–3 أسابيع

#### ✅ المهارات:
- المتغيرات، الشروط، الحلقات
- القوائم، القواميس، السلاسل النصية
- الدوال، التعامل مع الملفات

#### 🛠️ الأدوات:
- Python 3.x
- VS Code أو PyCharm
- موقع [W3Schools](https://www.w3schools.com/python/) أو [Sololearn](https://www.sololearn.com)

---

### ⚙️ المرحلة 2: أتمتة الملفات والمجلدات
**المدة المقترحة:** 1–2 أسبوع

#### ✅ المهارات:
- تنظيم الملفات تلقائيًا
- قراءة وكتابة ملفات `.txt`, `.csv`, `.xlsx`
- التعامل مع المجلدات

#### 🛠️ الأدوات:
- مكتبة `os`, `shutil`, `glob`
- مكتبة `pandas`, `openpyxl`

#### 📚 مصدر ممتاز:
- كتاب [Automate the Boring Stuff with Python](https://automatetheboringstuff.com)

---

### 📡 المرحلة 3: أتمتة الإنترنت والبريد الإلكتروني
**المدة المقترحة:** 2–3 أسابيع

#### ✅ المهارات:
- استخدام APIs
- إرسال واستقبال البريد الإلكتروني
- أتمتة التصفح

#### 🛠️ الأدوات:
- `requests`, `json`, `smtplib`, `email`
- `selenium`, `beautifulsoup`

#### 🎥 دورة مفيدة:
- [Google IT Automation with Python (Coursera)](https://www.coursera.org/professional-certificates/google-it-automation)

---

### 🧪 المرحلة 4: اختبار الأتمتة (Automation Testing)
**المدة المقترحة:** 1–2 أسبوع

#### ✅ المهارات:
- كتابة اختبارات تلقائية
- التحقق من صحة البرامج

#### 🛠️ الأدوات:
- `unittest`, `pytest`
- `Selenium` لاختبار واجهات المستخدم

---

### 🧰 المرحلة 5: أدوات DevOps وأتمتة النشر
**المدة المقترحة:** 2–3 أسابيع

#### ✅ المهارات:
- جدولة المهام
- أتمتة النشر والمراقبة

#### 🛠️ الأدوات:
- `cron`, `schedule`, `subprocess`
- `Docker`, `Git`, `CI/CD` (مثل GitHub Actions)

---

### 📁 المرحلة 6: بناء المشاريع وملف شخصي قوي
**المدة المقترحة:** مستمرة

#### ✅ المهارات:
- تنفيذ مشاريع عملية
- توثيق الكود ورفعه على GitHub
- كتابة سيرة ذاتية تقنية

#### 🛠️ أدوات مساعدة:
- GitHub
- Notion أو Trello لتنظيم التعلم
- LinkedIn لعرض المهارات

---

- سكربت ينظم الملفات تلقائيًا حسب النوع والتاريخ

- أتمتة تسجيل الدخول إلى موقع وجلب بيانات
